🔧 Configurer Google Business Profile

Suivez ces 4 étapes pour connecter votre fiche Google et activer la synchronisation des avis. Durée estimée : 10 minutes.

1
Créer un projet Google Cloud
console.cloud.google.com ▾

Rendez-vous sur la Google Cloud Console et créez un nouveau projet :

Ouvrir Google Cloud Console
  1. Cliquez sur "Créer un projet"
  2. Donnez-lui un nom : ex. fidelavis-prod
  3. Cliquez sur "Créer" et attendez quelques secondes
Si vous avez déjà un projet Google Cloud, vous pouvez l'utiliser directement.
2
Activer l'API Google Business Profile
Bibliothèque d'API ▾

Dans votre projet, activez les deux APIs nécessaires :

APIs à activer
  • My Business Account Management API — gestion des comptes
  • My Business Business Information API — info des établissements
  • My Business Reviews API — lecture et réponse aux avis
Activer My Business Account Management API
Activer My Business Business Information API
Activer My Business Reviews API (v4)
Pour chaque API : cliquez sur "Activer". Un message de confirmation apparaît quand c'est fait.
3
Créer vos identifiants OAuth 2.0
Identifiants ▾

Allez dans API et Services → Identifiants :

Ouvrir Identifiants OAuth

① Configurer l'écran de consentement OAuth (si pas déjà fait)

  1. Cliquez sur "Configurer l'écran de consentement"
  2. Choisissez "Externe" puis "Créer"
  3. Remplissez : nom de l'app (Fidelavis), email d'assistance
  4. Dans "Champs d'application", ajoutez :
    https://www.googleapis.com/auth/business.manage
  5. Ajoutez votre email en utilisateur test (mode développement)
  6. Sauvegardez

② Créer le Client ID OAuth

  1. Cliquez "+ Créer des identifiants" → "ID client OAuth"
  2. Type d'application : "Application Web"
  3. Nom : Fidelavis Web
  4. Dans "Origines JavaScript autorisées", ajoutez votre domaine :
Origines JavaScript autorisées : https://app.cartefidelavis.com // Si vous testez en local : http://localhost http://localhost:5500
⚠️ Ne renseignez pas d'URI de redirection autorisée — le flux implicite OAuth n'en a pas besoin.

Cliquez sur "Créer". Une boîte de dialogue affiche votre ID client :

123456789012-abcdefghijklmnopqrstuvwxyz123456.apps.googleusercontent.com

Copiez cette valeur — vous en aurez besoin à l'étape suivante.

4
Saisir le Client ID dans Fidelavis
Paramètres → Clés API ▾

Retournez sur Fidelavis et collez votre Client ID :

  1. Allez dans Paramètres → Clés API
  2. Collez votre Client ID dans le champ "Google Client ID"
  3. Cliquez "Enregistrer"
  4. Retournez en Dashboard et cliquez "Connecter ma fiche Google"
Une fenêtre popup Google s'ouvre. Connectez-vous avec le compte propriétaire de votre fiche Google Business Profile et autorisez l'accès.

Questions fréquentes
▾

L'API Google Business Profile est-elle gratuite ?
Oui, l'accès en lecture/écriture des avis via l'API est gratuit. Google Cloud offre un crédit de démarrage.

Mon compte Google doit-il être propriétaire de la fiche ?
Oui, vous devez être connecté avec le compte qui gère la fiche Google Business Profile (propriétaire ou gestionnaire).

Le token Google expire-t-il ?
Oui, après ~1 heure. Fidelavis vous avertira et vous devrez vous reconnecter. Cliquez simplement sur "Connecter ma fiche Google" à nouveau.

Mes données sont-elles envoyées à un serveur ?
Non. Fidelavis fonctionne entièrement dans votre navigateur. Les avis, paramètres et tokens sont stockés localement (localStorage). Seuls les appels directs à Google et Claude sont effectués.

L'erreur "access_denied" s'affiche
Vérifiez que votre email est bien ajouté comme utilisateur test dans l'écran de consentement OAuth (étape 3), si votre app est en mode "Externe" non publiée.

✅ Prêt à connecter !

Une fois votre Client ID configuré, retournez au dashboard et cliquez sur "Connecter ma fiche Google".
